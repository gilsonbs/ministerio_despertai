# Ministério Despertar - Website Institucional

Website oficial do **Ministério Despertar**, desenvolvido com foco em alta fidelidade de layout, design moderno, totalmente responsivo e interativo (agendamento de visitas, vídeo de boas-vindas, programação de cultos, eventos e contribuição online).

## 🚀 Recursos do Website

- **Design System Elegante**: Paleta de cores oficial (`#122A4E`, `#0C1E3A`, `#D9A32B`), tipografia nobre (*Playfair Display* & *Inter*) e componentes modernos.
- **Top Bar & Navbar Stick**: Informações de localização, horários dos cultos, redes sociais e menu de navegação com a logomarca oficial.
- **Hero Section de Alto Impacto**: Mensagem principal, botões de ação e destaques (*Adoração*, *Crescimento*, *Serviço*).
- **Seção Sobre Nós & Ministérios**: Apresentação da igreja e grid responsivo de 6 ministérios (*Infantil*, *Jovens*, *Jovens Adultos*, *Homens*, *Mulheres*, *Ação Social*).
- **Próximos Eventos & Contribuição Online**: Calendário de cultos e módulo para ofertas e doações online.
- **Faixa de Estatísticas & Depoimentos**: Métricas de impacto social e testemunhos reais de membros.
- **Modais Interativos**: Formulário de agendamento de visita (*Planeje sua Visita*) e player de vídeo de boas-vindas.

## 📁 Estrutura de Arquivos

```
├── index.html         # Estrutura HTML5 semântica em Português (PT-BR)
├── css/
│   └── styles.css     # Design system, variáveis de cores e responsividade
├── js/
│   └── app.js         # Lógica da aplicação, modais, menu mobile e contadores
├── images/
│   └── logo.png       # Logomarca oficial do Ministério Despertar

```

## 🛠️ Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador web ou rodar um servidor HTTP local:

```bash
# Exemplo com Python
python -m http.server 8080
```
